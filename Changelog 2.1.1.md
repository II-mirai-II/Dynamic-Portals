## Changelog 2.1.1 - UX and Progress Hub Fixes

This update focuses on quality-of-life improvements and interface consistency.

- Fixed progress chat spam: notifications now appear only when a requirement is completed.
- Fixed the extra "Details" button in the Progress tab: buttons now appear only for dimensions currently shown on the page.
- Removed visual redundancy in the Hub: the "Current state" line was removed where status is already shown in the card title.
- Adjusted Hub dimension display order: Nether first, End second, then custom dimensions (following TOML file order).

Validation build completed successfully after these fixes.
