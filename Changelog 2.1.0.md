## Changelog 2.1.0 - Progress + Party Hub Update

This is the main milestone of version 2.1.0.

- Introduced a dedicated Progress + Party Hub GUI as the primary player experience.
- Upgraded the mod from a mostly chat-command workflow to a focused in-game interface.
- Added a two-tab structure (Progress and Party) to keep core actions simple and fast.
- Added portal cards, requirement details, pagination, and clearer progression visibility.
- Added integrated party actions in the same screen: create, join, leave, and dissolve.
- Improved usability with responsive UI behavior across GUI scale and window size changes.

Commands are still supported, but the new Hub is now the central way to interact with the mod.
